Entry for the [One Word, First Thought](https://make.fun/competitions/u-0xkianno-one-word-first-thought-106abaf8) competition on [make.fun](https://make.fun).

## What it does

`main.ts` writes exactly one word — the first word that comes to mind — to `/output/entry.txt`. No topic, no explanation, no second draft. Just the word.

The word is **kerfuffle**: a commotion, a fuss, a flurry of feathers and raised voices. Surprising, vivid, and fun to say out loud.

## Run

```sh
node main.ts
```

Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` lands:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

Pure TypeScript with Node built-ins only. No dependencies, no network, no randomness — the same bytes every run.
